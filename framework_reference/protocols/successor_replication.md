# Successor and Replication Protocol

Successor packages include framework version, project manifest, discovery manifest, required protocols/bootstrap, accepted-state summary, integrity snapshot, current evidence pointers, active/open work, blockers, latest reviewed lessons, and communication schemas. Reconstruct current state from canonical evidence rather than requiring a human narration. Preserve governed audit history without blindly copying every historical item. Succession is a revalidation handoff, not automatic privilege transfer.
