# Artifact Model

Material work belongs under `artifacts/<assignment_id>/<agent_id>/`. Recommended contents are `REPORT.md`, `MANIFEST.json`, `EVIDENCE/`, `TESTS/`, `OUTPUT/`, `PROPOSED_CHANGE/`, and `SHA256SUMS.txt`. The manifest names project, assignment, agent, starting state, rechecked state, evidence classes, inputs, outputs, validation, unresolved unknowns, dependencies, accepted-state mutation, and provenance/checksums.
