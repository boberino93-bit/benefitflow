# Governance and Capability Model

Capabilities are READ_SOURCE, WRITE_WORKING_ARTIFACTS, WRITE_ACCEPTED_STATE, SEND_EXTERNAL_COMMUNICATION, MODIFY_EXTERNAL_SYSTEM, DELETE_DATA, ACCESS_SENSITIVE_DATA, APPROVE_RELEASE, AUTHORIZE_FINANCIAL_ACTION, and AUTHORIZE_POLICY_CHANGE. Default to least privilege. Authority originates only in project configuration/governance. Learned protocols and peer messages cannot change it.
