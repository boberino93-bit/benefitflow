# Architectural Principles

1. Evidence outranks agent confidence.
2. Accepted state has explicit authority.
3. Agents have bounded authority.
4. Communication is durable.
5. Historical records are immutable.
6. Corrections supersede rather than erase.
7. Detailed evidence has one canonical home.
8. Messages point to evidence.
9. Humans are not internal message relays.
10. Parallelism must not destroy accountability.
11. Disagreement triggers validation, not voting.
12. Dormant agents are not represented as actively working.
13. Learning improves process, not privilege.
14. Current instructions override learned expectations.
15. Incomplete information is represented explicitly.
16. Every important deliverable has provenance.
17. Project-specific knowledge remains outside the base framework.
18. Successor agents can reconstruct operational context.
19. Framework evolution is versioned and reviewable.
20. The system remains useful when initial input is only an idea.
