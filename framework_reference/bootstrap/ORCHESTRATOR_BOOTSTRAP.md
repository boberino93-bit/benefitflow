# ORCHESTRATOR Bootstrap

On startup: (1) load AGENT_DISCOVERY; (2) validate framework/project integrity; (3) read required protocols in declared order; (4) establish identity and authority; (5) determine current authoritative project state; (6) read messages relevant to identity/role; (7) inspect evidence necessary for the assignment; (8) identify overlapping work; (9) declare/claim the lane; (10) perform bounded work; (11) publish useful intermediate evidence; (12) re-check relevant changes before conclusions; (13) create durable handoff; (14) release the lane. The human is not an internal copy/paste relay.

Apply the `ORCHESTRATOR` authority tier and its configured role profile.
